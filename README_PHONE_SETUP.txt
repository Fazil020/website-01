PHONE-ONLY SETUP
=================

Folder structure:
birthday_surprise/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── her1.jpg
│   ├── her2.jpg
│   ├── her3.jpg
│   ├── her4.jpg
│   └── her5.jpg
└── music/
    └── song.mp3

1. Put your 5 photos into images/ and name them exactly:
   her1.jpg, her2.jpg, her3.jpg, her4.jpg, her5.jpg

2. Put your music file into music/ and name it exactly:
   song.mp3

3. You can edit the captions and memories directly in index.html using any phone text/code editor.

4. The secret code is 1622. It is intentionally only front-end JavaScript, so it is NOT real security.

5. For free phone-friendly hosting, a simple option is GitHub Pages:
   - Create/sign in to a GitHub account in your phone browser.
   - Create a new public repository.
   - Upload index.html, style.css, script.js, the images folder, and the music folder.
   - Open repository Settings → Pages.
   - Choose “Deploy from a branch”, select the main branch and root folder, then Save.
   - GitHub will provide a shareable pages link after deployment.

6. Another simple phone-friendly option is Netlify Drop:
   - Open Netlify in your phone browser.
   - Use its drag-and-drop/manual deploy option if available for your account.
   - Upload the whole birthday_surprise folder as a site.
   - Share the generated site link.

7. IMPORTANT:
   - Keep filenames lowercase and exact.
   - Avoid spaces in filenames.
   - If the music is large, compress it before uploading.
   - JPG/WebP photos around 1–2 MB each will load much faster on phones.
